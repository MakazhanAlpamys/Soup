They reached that unprompted, and likewise left four other docs pages alone on the reasoning that an extras hint mid-prose describes a package name rather than an install procedure ([#671](https://github.com/MakazhanAlpamys/Soup/issues/671), [#673](https://github.com/MakazhanAlpamys/Soup/pull/673))
