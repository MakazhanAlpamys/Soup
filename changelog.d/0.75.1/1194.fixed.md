- **`soup ui` opens and prints a login URL that already carries the auth token (#1194).** The first browser tab was `http://host:port` with no `?token=`, so every `/api/*` route except `/api/health` returned 401 and the dashboard rendered `Unauthorized`. The startup panel and `webbrowser.open` now use `http://host:port/?token=<token>`, including under `--no-browser`. `app.js` already reads that query parameter and removes it from the address bar.
