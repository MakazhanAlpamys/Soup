- **Layer streaming checks persistent LoRA adapter memory before checkpoint loading (#1).**
  Resolved PEFT tensor shapes determine adapter weights, gradients and supported
  optimizer states. Configurations exceeding available CUDA memory (including
  `stream_vram_override`) refuse before checkpoint resolution or shard writes,
  with a named byte breakdown. On refusal, smaller attention-only or
  attention-plus-shared-expert targets are suggested when their recalculated
  adapter budget fits. Unknown optimizer profiles do not claim a fit; passing
  this check does not guarantee full-step memory fit or equivalent model quality.
