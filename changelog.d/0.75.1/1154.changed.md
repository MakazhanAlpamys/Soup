- **An explicitly requested FP8 run now stops when torchao is missing, instead of training in bf16 (#835 by @Srinivasan8888 in #1154).**
  With `quantization_aware: fp8` or `fp8_attention: true` on a card that can run
  FP8, a missing torchao used to print a yellow advisory and train without FP8,
  under a config that said FP8. It now stops at setup with
  `FP8DependencyMissingError`, naming `pip install "soup-cli[qat]"`, the same way an
  unsupported card already stops. A box with transformer-engine but no torchao
  stops too, because the converter is torchao's. A config that does not ask for
  FP8 is unaffected. If your runs relied on the old fallback, remove the FP8
  setting or install the extra.
