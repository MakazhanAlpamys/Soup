- ``task: unlearn`` runs no longer finish with a ``KeyError: 'duration'`` traceback
  instead of the completion panel. ``UnlearnTrainerWrapper`` was the only wrapper
  returning ``duration_secs`` without the pre-formatted ``duration`` the panel
  reads, and the panel indexes that key after ``finish_run()`` has already
  recorded the run as complete. The wrapper now returns both forms, and the
  panel renders from ``duration_secs`` when the string form is absent so the next
  wrapper that forgets the key degrades instead of crashing a finished run. A
  contract test over ``trainer/*.py`` asserts every wrapper that reports
  ``duration_secs`` also reports ``duration`` (#1529 by @Yi-111-a in #1539).
