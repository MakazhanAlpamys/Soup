- **`soup expect` fails closed on unreadable JSONL input (#1434).** The gate now reads the dataset as `utf-8-sig` like the training loader, so a UTF-8 BOM no longer hides the first row from PII and other checks. Malformed JSON lines and valid JSON that is not an object are refused as an input error (exit 3) with their line numbers instead of being silently skipped, and a file with no checkable rows is refused rather than passing with `Rows 0`.
