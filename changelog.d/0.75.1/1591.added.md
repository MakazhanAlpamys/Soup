- **Added `--require-all-modes` to `soup diagnose --evidence` (#1525 by @bakdauletbaktygaliyev in [#1591](https://github.com/MakazhanAlpamys/Soup/pull/1591)).** By default a mode missing from the evidence file reads as a neutral OK, so an evidence file with no scores passes. With the flag every absent mode is `NOT_RUN` ("no evidence supplied"): the run exits 3 unless `--allow-not-run`, and MAJOR still exits 2. The same switch is available as `soup train --diagnose-gate-require-all-modes` (requires `--diagnose-gate`) and as the `require_all_modes` argument of the MCP `diagnose_evidence` tool. The default behaviour is unchanged.
