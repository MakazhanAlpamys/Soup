- **`soup migrate` explicitly writes `quantization: none` and emits `lora.r: 0` for full fine-tuning (#1215 by @kok-o).** Previously, unquantized Axolotl, LLaMA-Factory, and Unsloth configurations omitted the quantization field, causing Soup to default them to 4-bit QLoRA upon loading, while full fine-tunes defaulted to LoRA `r=64`. Migrators now explicitly set `quantization: none` for unquantized sources, support HQQ/EETQ methods, map full fine-tunes to `lora.r: 0`, refuse full fine-tuning for unsupported tasks (e.g. DPO/PT/RM), resolve notebook variable assignments in Unsloth, and validate output with `load_config_from_string` before writing.
