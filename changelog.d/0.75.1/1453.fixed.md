- **`soup data clean --repair-json` and `--drop-invalid-json` missed nested tool calls and dropped valid documented-shape rows (#1338 by @abdulwaarith0 in #1453).** Both flags read only a flat `arguments` key on the row's top-level `tool_calls`, so calls inside an assistant turn (what `soup agent synth` writes, and the OpenAI fine-tuning shape) were never repaired or checked, and a valid `{"function": {"arguments": ...}}` call read as `""` and got its row dropped. They now read every call the tool-calling loader reads, in both shapes, and leave dict arguments alone.
