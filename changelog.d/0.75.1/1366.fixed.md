- **The friendly error reads a 401/403 out of the whole exception chain, not just the outer message (#1361 by @putramkti in #1366).** `_auth_status` walks `__cause__`/`__context__` when it reads a status off the exception object, but its phrasing fallback searched only `str(exc)`, so a library that wraps a text-only auth failure, as peft and transformers do, printed `RuntimeError: Failed to load adapter` where the same 401 on its own prints `Authentication failed.` The fallback walks the chain too, exception-major, so the outermost exception that states a status decides and a 403 wrapper of a 401 still reads as the 403 it says.
