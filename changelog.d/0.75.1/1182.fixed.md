- **`soup data preprocess` stops on a chat row it cannot tokenize, instead of dropping it (#1180 by @Srinivasan8888 in #1182).**
  A row the chat template rejected (for example `Conversation roles must alternate` on a
  Llama-2- or Gemma-style template), an empty `messages` list, or a tokenizer error was
  skipped without a word, and the command exited 0. A `pre_tokenized` run then trained on
  fewer rows than the live run of the same `soup.yaml`, which stops on those rows. The
  command now exits 1 before writing anything, naming the row's train-split index and the
  start of its first message. Fix or remove the row and re-run.
