- **`soup export --format awq` and `--format gptq` are deprecated and will be removed in the next release.** Both upstream projects (AutoAWQ and AutoGPTQ) are archived, neither extra can be installed next to `[train]`, and `auto-gptq` has no Python 3.12 wheel, so the two formats could not be reached from a normal install. Until the removal they work as before. The command now starts with a `Deprecated:` notice that names the formats to move to (`gguf`, `onnx`, `tensorrt`, `bitnet`, `tq1_0`), so it is there whatever stops the run, the missing extra included; `soup quantize --to awq` and `--to gptq` print the same notice after the command they hand you; and the `--format` and `--to` help texts mark both formats (#1690).
