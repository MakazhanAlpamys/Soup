- **`soup migrate` maps every LLaMA-Factory `pref_loss` and TRL trainer class to its Soup task, and refuses the rest by name (#1214 by @Srinivasan8888 in #1560).** LLaMA-Factory `stage: dpo` with `pref_loss: ipo` now migrates to `task: ipo` instead of plain `dpo`; `hinge`, `kto_pair` and any other value with no Soup task make `soup migrate` exit 1 naming the value and the supported list, instead of loading as `dpo` with no warning. Unsloth notebooks: `RewardTrainer` -> `reward_model`, `BCOTrainer` -> `bco`, `OnlineDPOTrainer` -> `online_dpo` (with a warning that the judge / reward model is not carried over), and `CPOTrainer` -> `simpo` only when the `loss_type="simpo"` on that trainer's own call or its `args=` config; other CPO losses are refused. `SFTConfig` and the other TRL `*Config` classes are now read for hyperparameters, so a notebook passing `args=SFTConfig(...)` keeps its batch size, epochs, learning rate and output directory. The axolotl migrator was settled by #1254.
