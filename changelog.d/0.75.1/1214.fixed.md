- **`soup migrate --from axolotl` no longer turns `rl: orpo`, `rl: ipo`, and
  `rl: simpo` into `task: sft` with no warning (#1214).** `_RL_MAP` only
  covered `dpo`, `kto`, `grpo`, and `gdpo`; every other `rl` value fell
  through to `sft` silently, so a preference config loaded with the wrong
  task and the wrong data format and later failed training with an error
  that never named `rl`. `_RL_MAP` and `_TASK_FORMAT_MAP` now cover `orpo`,
  `ipo`, and `simpo`, mapping each to its matching Soup task and the `dpo`
  data format. An `rl` value with no Soup task, such as axolotl's `ebft`,
  still falls back to `task: sft`, but now appends a `_warnings` entry
  naming the unmapped value.
