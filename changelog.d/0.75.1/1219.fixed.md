- **Fix classifier, reranker, and cross_encoder data loading and row validation (#1219 by @kok-o).** Sequence classification tasks (`classifier`, `reranker`, `cross_encoder`) were losing dataset columns such as `label`, `text_a`, `text_b`, `question`, and `answer` during dataset normalization because `preserve_source_columns` was restricted to `task == "grpo"`, causing crashes with `TypeError: label must be int / str / list, got NoneType` after model loading. In addition, `cross_encoder` rows had no recognized format signature or schema format enum. Centralized source column retention in `task_preserves_source_columns` shared across `soup train` and `soup sweep`, added `cross_encoder` format detection and schema support, and added upfront dataset label and shape validation that fails immediately at data load and on `--dry-run` with specific row indices before model weights are loaded.
