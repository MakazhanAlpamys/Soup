- `soup infer`, `soup chat` and `soup diff` now honor `--device` when loading
  models instead of always passing `device_map="auto"` and
  `torch_dtype=torch.float16` to `from_pretrained` (#1443). A resolved
  `--device cpu` (explicit or auto-detected) previously still let
  `accelerate` place the model on any visible GPU and loaded it in an
  unsupported CPU dtype; the model is now pinned to the resolved device with
  a device-appropriate dtype (`float32` on CPU, `float16` elsewhere).
