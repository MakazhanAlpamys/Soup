- `soup reward synth`'s numeric verifier now reads both the gold and the completion with the shared answer parser the built-in `math` / `accuracy` rewards use, so `1,000`, `#### 1,000`, `\boxed {42}` and `#### −42` spellings score the same under the generated verifier as under the built-ins, and malformed comma groupings like `10,00` are no longer detected as numeric. A `reward.py` synthesized before this version scored those spellings 0, so regenerate it before comparing runs; the emitted file now imports `soup_cli` rather than being fully self-contained. The calibration report and `--output-report` also name every reference the verifier rejects (`rejected_references`) instead of reporting only a refusal rate (#1350 by @Momoyeyu in #1533).
