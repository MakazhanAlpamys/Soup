- Refuse ten optimizer names at config load instead of crashing inside the trainer: transformers 5.x rejects `adam_mini`, `adamw_apex_fused`, `adamw_hf`, `ao_adamw_fp8`, `ao_adamw_4bit`, `ao_adamw_8bit`, `badam`, `came_pytorch`, `dion` and `muon` in `TrainingArguments`, so each used to pass config load and fail after the model had loaded. They are removed from the allowlist with a message naming working alternatives, the LoRA-FA validator no longer recommends `adamw_hf`, and a new test builds `TrainingArguments(optim=name)` for every allowlisted name so a rejected name fails the suite instead of a user's run (#1269).
