- Fixed `soup serve --device` being echoed and then ignored: the transformers loader now resolves `--device` (`cpu`, `cuda`, `cuda:<index>`, `mps`, case-insensitive) into the `device_map`/`torch_dtype` handed to **every** `from_pretrained` call, so a forced CPU load stays on the CPU in float32 (a `kv_cache_dtype: bfloat16` still loads bf16), an unknown value is refused with an error naming the accepted values instead of silently defaulting to `device_map="auto"` + float16, and the main model and its speculative draft can no longer land on different devices for the same flag (#1478 by @wanjinhao1 in #1480).
