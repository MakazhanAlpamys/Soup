- **`soup init` refuses a symbolic link or junction at the config path it writes, and MCP planning creates the config snapshot's run directory fresh (#1553).**
  `soup init` wrote the starter config with a plain write that follows a link at the target (`soup.yaml` or `--output`), and a dangling link even skipped the overwrite prompt. It now refuses a symbolic link or junction there before prompting or running the wizard, naming the path, and opens the file without following a link, matching the link refusal the other config writers apply. Ordinary paths, including ones outside the working directory, behave as before. Following #1492, `train_start` under `soup mcp serve` now also checks the run directory `.soup/mcp-runs/<run_id>` itself, creates it with `exist_ok=False`, and creates `config.yaml` exclusively (`O_EXCL`) without following a link, refusing the plan with a path-free error when the run directory or the file already exists or is a link.
