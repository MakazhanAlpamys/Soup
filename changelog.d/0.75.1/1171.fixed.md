- **Hardened MCP run-log opens against directory symlinks in parent path and pre-planted hardlinks (#1158 by @kok-o in #1171).**
  Following #1138, `open_no_follow` now inspects parent directory components for symlinks and reparse points when `check_parent=True`, and rejects hardlinked regular files (`st_nlink > 1`) when `refuse_hardlink=True`. `ExecutionManager.execute()` verifies parent directories before creating `mcp-runs` and opens the log with both protections, closing uncoordinated directory redirection and pre-planted hardlink overwrite (with a residual TOCTOU window if an attacker has concurrent write access inside `.soup`).
