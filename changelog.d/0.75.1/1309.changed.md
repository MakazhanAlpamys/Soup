- **Breaking: `training.gdpo_variant` is now refused at config load (#1309).** Every non-null value is refused, including `standard`, `length_normalized` and `margin`; unset and null still load. On supported TRL versions (0.29 and later) the setting previously loaded but silently changed nothing because `DPOTrainer.dpo_loss` no longer exists. Remove `gdpo_variant` and use plain `task: dpo` for `standard`; `task: simpo` is the nearest, not identical, objective for `length_normalized`; `margin` has no equivalent. GDPO metadata no longer advertises live wiring, and the retained legacy helper raises instead of silently ignoring a missing loss hook. No new loss implementation is added; no shipped recipe, template or example sets this field.
