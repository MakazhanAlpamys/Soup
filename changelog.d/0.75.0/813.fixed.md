- **Unify exit codes across gate and verdict commands under a single 0/2/3 taxonomy (#813).**
  `soup eval gate`, `soup eval against`, `soup eval checklist`, `soup eval behavior`,
  `soup eval quant-check`, `soup lock check`, `soup data validate`, `soup data lint`, and
  `soup ship` now consistently return exit code `0` on pass / OK / minor / ship, exit code `2`
  on gate failure / regression / drift / don't ship / unusable data, and exit code `3` on
  usage errors (missing or unparseable input files, bad flags). Exit codes are defined as
  shared constants in `soup_cli.utils.exit_codes`. CI workflow and pre-push hook templates
  now distinguish gate failure from misconfiguration.
