- Remove orphaned `build_bitnet_trainer` and `validate_bitnet_compat` from `utils/bitnet.py`, unreachable after schema-level rejection of `quantization: bitnet_1.58` training (#1004 by @VanshSharmaPES in #1034).
- **Fix `AsyncDiskSource`'s liveness check intermittently misreporting a healthy reader as one that "exited without recording an error" (#1034).** `_run`'s only silent exit path was guarded by `self._closed`, but nothing forced `_error` to be set, under the same lock, before `is_alive()` could report the thread gone — leaving a narrow window where `get()`'s backstop check fired on a reader that had not actually failed. `_run` now wraps its loop in a `finally` that stores a fallback `RuntimeError` for any exit that skipped both the guarded `return` and `_fail`, and `_fail` no longer overwrites an earlier recorded error.
