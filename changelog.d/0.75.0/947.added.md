- **`soup doctor` now reports GPU architecture and precision capability diagnostics (#829 by @Samearth17 in #947).** GPU diagnostics show the detected NVIDIA compute capability and architecture, whether the installed Torch build includes native/PTX support for that GPU, and hardware/software support for BF16, FP8, and NVFP4. Unsupported GPU architectures now include a CUDA-enabled PyTorch reinstall hint, and the TorchAO floor is synchronized at `0.7.0`.
