- ReLoRA restarts now follow the paper contract (#693): each fire merges the LoRA update into the base weight, reinitializes `lora_A`/`lora_B`, clears optimizer state when `relora_reset_optimizer` is set, and re-warms the learning rate. Unsupported combos (`quantization` other than `none`, `stream_layers`, VeRA, DoRA, FSDP2 compile, MLX) are rejected at schema parse time instead of half-applying. `relora_prune_ratio` is deprecated (kept for YAML compatibility; adapter weights are no longer pruned). The magnitude-prune helper now uses exact keep-count under ties. Rejects optimizers without a `.state` dict before merging (wrapped DeepSpeed/FSDP optimizers). Merged base deltas remain in-memory until `soup merge` exports a dense checkpoint.
