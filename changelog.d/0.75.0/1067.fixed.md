- **Include `data.chat_template` in `soup data preprocess` cache key derivation (#1067).** Two configurations differing only in their chat template previously resolved to the same pre-tokenized cache entry, allowing subsequent runs to silently train on tokens rendered by an unintended template. `make_preprocess_cache_key` now binds `data.chat_template`, `metadata.json` persists the template, and legacy pre-existing caches lacking recorded template metadata are explicitly refused at load time with an actionable message directing users to re-run `soup data preprocess` (#1067 by @kok-o).
