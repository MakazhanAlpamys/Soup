- **Both FP8 training paths ask one hardware gate, with torch's own floors, and a request the card cannot run stops the run (#835 by @Srinivasan8888 in #1044).** `training.fp8_attention` refused Ada (sm_89) cards such as the RTX 40-series, L4 and L40S, which `torch._scaled_mm` supports, while `training.quantization_aware: fp8` converted the model on any card, Ampere included. Both now require compute capability 8.9 or newer. The `rowwise` recipes also need a torch that dispatches their kernel on the card (Ada 2.7, RTX 50-series 2.8, 11.x 2.10), are never available on Windows, and before torch 2.11 need a CUDA 12 build. When FP8 is requested and cannot run, the run now stops at setup on every trainer, naming the reason, instead of warning and training without FP8.
