- **Both FP8 training paths ask one hardware gate, with torch's own floor (#835 by @Srinivasan8888 in #1044).** `training.fp8_attention` refused Ada (sm_89) cards such as the RTX 40-series, L4 and L40S, which `torch._scaled_mm` supports, while `training.quantization_aware: fp8` converted the model on any card, Ampere included. Both now require compute capability 8.9 or newer. The `rowwise` recipes on Ada also need torch 2.7, the first release with an sm89 rowwise kernel. A card below the floor is refused with the reason before any layer is converted.
