- **A layer-streamed LoRA run could save an empty or corrupted adapter without warning (#1011).** Twice in Soup's history, a streamed run wrote an unusable adapter (`.inner.` wrapper leakage in v0.72.0, and a 0-tensor 40-byte `adapter_model.safetensors` on peft 0.21 in #1005) while exiting 0 and only producing warnings at later reload time. Added `assert_streamed_adapter_saved` post-save verification on the production save path (`install_streamed_save_guard` wired into `build_streamed_model` and `install_streaming`), asserting that `adapter_model.safetensors` exists, contains `> 0` tensors, matches the expected trainable `lora_*` parameter count, and carries no `.inner.` wrapper leakage. If verification fails, it raises `RuntimeError` immediately rather than emitting an ignorable warning. Legitimately empty models (0 trainable LoRA parameters) are deliberately excluded. CPU-visible and verified with a mutation test reproducing the #1005 divergence.
