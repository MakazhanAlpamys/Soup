- **Added optional PEFT LoRA-FA (Frozen-A LoRA) optimizer support via `training.use_lorafa`
  (#725 by @webdevsamran).**
  Freezes LoRA A matrices and updates only B matrices via PEFT''s `create_lorafa_optimizer`
  (arXiv:2308.03303), eliminating the need to store input activations for backpropagating
  through A and reducing adapter-rank activation memory retention substantially during training.
  Wired into the SFT, pretrain, and embedding trainers post-construction so `Trainer.create_optimizer`
  respects the custom optimizer while building the scheduler from it. Rejects incompatible
  combinations (LoRA+, GaLore, and non-LoRA runs) with explicit errors.
