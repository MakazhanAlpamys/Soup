- **`target_modules: auto` now resolves on every MoE architecture Soup ships a recipe for (#1070 in #1102).**
  peft has no LoRA mapping for `qwen3_moe`, `deepseek_v3`, `deepseek_v4`,
  `glm_moe_dsa`, `kimi_k25` or `minimax_m3_vl`, so `auto` reached it as `None` and

  found` — for all 31 shipped MoE recipes. Each now resolves to the attention
  projections that architecture actually defines. MiniMax-M3 resolves to a regex
  scoped to its language tower, so a text fine-tune no longer adapts the vision
  encoder.
- **An architecture neither Soup nor peft maps is refused by name (#1070 in #1102).**
  It raised before as peft's `No target_modules passed`, which named neither the
  architecture nor where to fix it. The refusal is suppressed when
  `training.lora.target_parameters` is supplied, which peft accepts on its own.
