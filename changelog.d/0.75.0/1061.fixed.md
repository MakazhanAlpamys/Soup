- **An untied streamed checkpoint takes a preference step again (#1049 by @dchaudhari7177 in #1061).** `embed_tokens` and an untied `lm_head` share one device slot, and the streamed layer passed autograd a view of it, so the reference forward of `dpo` or `kto` refilled those bytes in place and the policy backward raised `one of the variables needed for gradient computation has been modified by an inplace operation`. The projection now takes a private copy of its weight, one head-sized buffer per step, and only when the slot is shared and a backward can follow; the embedding keeps the view, because its backward reads the indices rather than the weight values. Llama-3-8B-class checkpoints are untied, so this is the common shape; tied runs and `sft` were unaffected.
