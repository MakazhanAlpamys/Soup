- **`soup reward stress` now detects structure-preserving attacks that game built-in format and substring verifiers (#814 in #918).** `reward_stress` previously checked four classic junk strings (`empty`, `length`, `repetition`, `sentinel`), none of which exercised the structure rewarded by reasoning scaffolds. Consequently, the built-in `format` reward was reported as "robust (not gameable)" despite awarding 1.0 to `<think></think>a`, and `accuracy` missed distractor answer-sprays. `soup reward stress` now adds three structure-preserving attack families (`wrapped_junk`, `answer_spray`, and `structure_without_content`), expands each family into multiple distinct variant attempts, tests `answer_spray` against real gold substitutions, and ensures `verifiable` math checks remain robust (exit 0).
