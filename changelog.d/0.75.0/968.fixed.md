- **Data recipes no longer report an unreachable provider as a successful run (#930 by @taljeon in #968).** Live `llm_text` and `judge` nodes now count transport, non-2xx, and malformed-response failures; a node whose every provider call fails exits non-zero and names the endpoint. Partial runs keep their successful rows and report the failure count, while a legitimate empty completion remains a successful response rather than being mistaken for an outage.
