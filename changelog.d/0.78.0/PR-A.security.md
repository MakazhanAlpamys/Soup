- The commands Soup prints for you to copy (the retry line of a Modal download and the follow-up commands after a training run) now spell the `output` path so that no shell reads part of it as syntax: ordinary paths are repeated as before, a path with spaces or punctuation is wrapped in double quotes, and a path a shell could still interpret is replaced by a placeholder with a one-line note, so type it yourself in that case. The `soup train --cloud` run command also quotes its stub file name. (#PR-A)
