- The commands Soup prints for you to copy (the retry line of a Modal download and the follow-up commands after a training run) now spell the `output` path so that no shell reads part of it as syntax: ordinary paths are repeated as before (on Windows a nested path is written with forward slashes), a path with spaces or punctuation is wrapped in double quotes, and a path a shell could still interpret is replaced by a placeholder with a one-line note, so type it yourself in that case. The paths in the sentences around the Modal commands are shown in single quotes. The `soup train --cloud` run command also quotes its stub file name, and the `soup prune-layer-cache` command that the layer-streaming disk check prints spells the base model the same way. (#PR-A)
