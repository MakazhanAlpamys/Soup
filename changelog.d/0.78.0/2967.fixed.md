- `soup data mix --live` isolates each candidate’s run, tracker and output. `best_loss=` and the
  chosen weights now use each candidate’s own final-step validation loss, so rerunning a search
  can produce different weights. Previously, unsupported base recipes could start training,
  missing final evaluations could fall back to training loss, and an entirely failed search
  could write a uniform recipe with `best_loss=n/a`. Invalid or unsupported base recipes now
  exit 2 before training. Use a valid `--base-yaml` for text SFT on Transformers with raw local
  data, `data.streaming: false` and `data.val_split > 0`. Candidates missing final validation
  are skipped. Remove `training.eval_steps` to evaluate each epoch. If no candidate has a valid
  score, the command exits 2 without writing a recipe. (#2967)
