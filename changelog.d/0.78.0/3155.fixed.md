- `soup loop`'s sft recipe `quantization: auto` now counts a base the Hugging Face cache holds when the Hub is offline (`HF_HUB_OFFLINE=1`): its cached safetensors headers, else its cached `config.json`. So an offline run with a cached base that fits in free VRAM now trains without quantization, where it always trained in 4-bit before; pass `--sft-quantization 4bit` to keep the old choice. A size in the repo name is not taken as a count. The decision, with where the count came from or why it is unknown, is now also on the train line of `.soup-loops/progress.jsonl`. (#3033 in #3155)
