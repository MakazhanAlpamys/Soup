- **`training.packed_lora` runs the Qwen2 QLoRA SFT step through the Triton kernels of #2623 (opt-in, CUDA, Linux) (#3178).** `soup train` checks the machine, the model config and the settings before loading weights or training data. It requires a single visible CUDA device, prints the memory plan, and reports why it cannot use the kernels. Set `on_unsupported: stock` to use the stock step when the kernels are unsupported. If the plan exceeds available pinned host RAM or GPU memory, `--allow-oom-attempt` allows the run to proceed. The log reports `steps: N packed, M stock`. Evaluation, generation, merge and save use the stock forward. Set an explicit `training.batch_size`, `lora.dropout: 0` and `quantization: 4bit`. `gpu_budget_mib` targets torch's estimated peak allocated GPU memory. Built on the Soup Kernel Challenge submission of team Luck, with ideas from teams 21, Null Pointers, DarkDaur and OrbiTeam.
