- **`soup eval` / `soup ship` gate: an echo of the option list no longer scores as an answer, and "A is the correct answer." does.** The multiple-choice letter extractor read the last option marker of an output that only repeated "(A) x (B) y (C) z" as the model's choice, so a model that never answered passed every item keyed on the last option. A bare letter, a wrapped letter, a box or an explicit cue after the list still counts. The letter-first form ("A is the correct answer.", "(B) is correct") now reads as that letter wherever it appears, and a lone leading letter after whitespace is read too. `BUNDLED_SCORER_REVISION` is 9; baselines stamped with an older revision warn once, as for earlier scorer changes.
