- `soup ingest --source langsmith` now reads LangChain chat model runs, whose `inputs.messages` is a batch of serialised messages, and OpenAI-style runs, whose answer is in `outputs.choices`. Both gave no row before. A serialised message takes its role from `kwargs.type` and its text from `kwargs.content` in every trace parser, and a class with no role is left out of the prompt. A run whose batch holds several prompts still gives no row. When a run has no `generations` and carries both `choices` and another output key such as `output`, the answer is now read from `choices` first. (#2868 in #2942, reported by @omardmv)
