- JSONL rows that hold U+2028, U+2029 or U+0085 inside a JSON string are now read by the best-of-N candidate artifact and judgments, the `soup-jsonl-c14n-v1` digest, the `--prompts` file of `soup export --format onnx --validate-onnx`, the eval suite of the prompt compiler and the packaged battery, gate and loop fixtures; such rows were refused or silently dropped before, and no stored digest changes. A line of a plain-text `--prompts` file that holds U+0085, U+2028, U+2029, VT, FF or U+001C-U+001E is now one prompt, and a JSONL file whose rows end with one of them instead of a line feed is now read as one row and refused (the prompt compiler skips it); end each row with a line feed (#3066 by @Adul23 in #3116).
