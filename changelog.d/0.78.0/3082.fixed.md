- `soup adapters merge --strategy svd --rank` now truncates each LoRA module's merged delta `B·A` to its best rank-N approximation, written back as factors zero-padded to the input rank. It used to truncate `lora_A` and `lora_B` separately, which could write a delta of 0 and depended on how the inputs split their delta between the two factors; a merge with `--rank` below the LoRA rank now writes a different adapter. Full tensors saved with the adapter, such as a `modules_to_save` classifier head, are no longer truncated. Merges without `--rank`, or with `--rank` at or above the LoRA rank, write the linear merge.
