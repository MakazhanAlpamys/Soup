- `soup data score`, `decontaminate`, `toxicity`, `langdetect`, `pii` and `educational` no longer drop rows without saying so. A line that is not valid JSON or not a JSON object gets the warning `soup data clean` gives, and the panel counts it (`Input: 2 (2 lines skipped)`; `score` adds a `Skipped lines` row); an input of only such lines is refused with `no object rows remain: N row(s) skipped (listed above)`. A file over 1,000,000 rows, as `--input` or as the `--benchmark-file` of `decontaminate`, now exits 1 with `file exceeds 1000000 rows` before any output is written; on v0.78.0 it was read only up to row 1,000,000 and the command exited 0 with a result for part of the file. If a script relied on that, split the file into parts of at most 1,000,000 rows (#3376 by @abdulwaarith0 in #3435).
