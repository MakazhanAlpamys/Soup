- `soup prune-layer-cache --model <value>` now refuses a `<value>` that can be neither a Hub id nor a path, instead of printing `Nothing to prune.` and exiting 0 (#3088 by @artikulus1301 in #3128). A path-like value that does not exist prints `Model path not found: ...`; a value that cannot be a Hub id prints `Invalid --model: ...`; both exit 1. This is the resolution `soup bench` and `soup infer` already use.

  A `--model` such as `"bad name"` (whitespace, a `..` segment, or an over-long id) loaded before and is now refused at start-up; pass a Hub id (`owner/name`) or a path that exists.
