- `soup airgap-bundle --bundle-size-cap` now refuses `nan`, `inf` and a cap too large to count in bytes (above about 1.67e299 GiB) as a usage error that names the option (exit 2), before anything is read: `--bundle-size-cap must be a finite number > 0` or `--bundle-size-cap is too large to count in bytes`. They used to pass the `> 0` check and then stop in the conversion to bytes with an internal `ValueError` or `OverflowError` and exit 1. Every cap that built a bundle before still builds one (#3045 by @Keshemir in #3076).
