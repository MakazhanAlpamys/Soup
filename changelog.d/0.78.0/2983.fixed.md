- `soup train --cloud` exits 2 before planning for CLI options it cannot apply remotely. Earlier versions could exit 0 after dropping the options or attempt a live submission with `--cloud-submit --dry-run`. Combining `--find-lr` with `--cloud` now exits 2. Previously it ran the sweep locally and exited 0 on success or 1 on failure. See [Cloud GPU Training](docs/backends-and-ops.md#cloud-gpu-training) for the refused options. Use local training for unsupported flags and omit `--cloud-submit` to preview the cloud plan. `--name` is passed in the effective config when no experiment name is set (#2983 by @Nari-Ab).
