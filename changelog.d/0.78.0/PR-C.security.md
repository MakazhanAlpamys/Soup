- The code-execution sandbox (the RLVR `code_exec` reward, the `soup serve` python and bash tools, the agent-eval and recipe runners) now ends the processes the checked code started, not only the direct child, when the run times out, floods its output or exits: a process group on Linux and macOS, a job object on Windows. A sandbox directory that cannot be removed no longer aborts the caller. Results and exit codes of runs that finish normally are unchanged. The sandbox stays best-effort and is not a security boundary: a process that deliberately leaves its process group is not reached on Linux and macOS. (#PR-C)
