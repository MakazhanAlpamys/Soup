- On a case-insensitive volume, `soup eval gate --write-baseline` could overwrite the suite, tasks or prompts file using a different spelling and exit 0. It now exits 3 with an alias message for a path to the same input, including a bind mount to a one-link file, while allowing separate hard links. Choose a different `--write-baseline` destination when upgrading from v0.78.0 (#2747 by @taljeon in #2790).
