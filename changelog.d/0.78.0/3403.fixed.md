- Layer streaming of an FP8 block-quantised base (DeepSeek-V3, Kimi K2) now shards NF4 without double-quant by default: an unset `training.bnb_4bit_use_double_quant` resolves to off for that base, an explicit `true` is refused by name, and `stream_nf4_scale_cache` is refused for it, because with double-quant on the NF4 codec exceeds the per-block reconstruction bound on block-scaled weights whose block scales span a wide range. Every other base keeps double-quant on. (#3403 by @Lameda12)
