- **`soup eval` / `soup ship` gate: an echo of the option list no longer scores as an answer, and "A is the correct answer." does.** The multiple-choice letter extractor read the last option marker of an output that only repeated "(A) x (B) y (C) z" as the model's choice, so a model that never answered passed every item keyed on the last option. A bare letter, a wrapped letter, a box or an explicit cue after the list still counts. The letter-first form ("A is the correct answer.", "(B) is correct") now reads as that letter wherever it appears, and a lone leading letter after whitespace is read too. This is a scorer change: `BUNDLED_SCORER_REVISION` moves to 9. A baseline with an earlier scorer revision (a `--write-baseline` file or a registry eval row) still loads and is compared, and `soup eval gate --baseline` and `soup ship --baseline` warn about the `scorer_revision` mismatch. A stored multiple-choice score used the old extractor, so the comparison can show a change caused by the scorer. Re-measure with `soup eval gate --suite <suite.yaml> --model <id> --write-baseline baseline.json`. (#3397 by @nurseit14)
