  and numerics stamp; omitting `--device` moves them from CPU to the live device (CUDA
  when available), which can change scores and increase GPU memory use. Runs allowed
  by v0.78.0 with lm-eval 0.4.0 or devices outside CPU/CUDA/MPS are now refused before
  loading: upgrade to lm-eval>=0.4.1 and select `--device cpu`, `cuda` or `mps`; these
  preflight refusals and model names containing `,` or `=` now exit `3` instead of `1`
  (#3366 by @here-2007 in #3470).
