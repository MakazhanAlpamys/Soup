- `training.prefix_tree: true` no longer passes its setup check when the model produces NaN or infinite logits. The check that compares a prefix-tree row with the ordinary batch used to drop a NaN difference and could call the layout exact, so training started on rows nobody had verified. A nonfinite ordinary batch, single-example run or prefix-tree row now makes the check fail, and when both mask forms fail SFT stops before training with an error naming the forward whose logits are not finite (#3223 by @SajjadPSavoji in #3382).
