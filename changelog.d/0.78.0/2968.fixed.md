- `soup data split` refuses requests that yield no split at all (`--val 0`, `--test 0`, or both
  in percentage and absolute modes) and percentage splits summing to 100 or more with exit 1
  instead of silently omitting split files or inverted remainders (#2968 by @Shubham-dev-stack).
  Inputs that previously exited 0 now exit 1: `--val 0` or `--test 0` with no other split,
  `--val 0 --test 0`, and percentage splits totalling 100% or greater on small datasets where
  truncation kept counts below dataset size. Passing `--val 0 --test 10` or `--val 10 --test 0`
  continues to work to request a single partition.
