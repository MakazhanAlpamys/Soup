Expert shard storage moves into its own module, `utils/expert_shard.py`, with the readers and writers hardened: the reader checks the staging buffer, the expert id, the NF4 spec pair, the expert MLP shapes and the set of tensors in the file; the writer checks the NF4 codec output and that every expert is one gate_up and down pair. The index fields written and the format version (5) are unchanged, existing per_expert caches load as before, and an index that also carries `expert_layout_version` loads too (port of SoupTeam/soup-rnd#24 by @Artix6034, hardening from #45 by @kok-o)
