Expert shard storage moves into its own module, `utils/expert_shard.py`, with the readers and writers hardened: the reader checks the staging buffer, the expert id, the NF4 spec pair, the expert MLP shapes and the set of tensors in the file; the writer checks that every expert is one gate_up and down pair and that the NF4 codec output keeps its contract. The index fields written and the format version (5) are unchanged, existing per_expert caches load as before, and an index that also carries `expert_layout_version` loads too (by @Artix6034, @kok-o)
