- `DELETE /api/runs/{id}` and `GET /api/runs/{id}/eval` of `soup ui` take a unique run id prefix, as `GET /api/runs/{id}` and `soup runs delete` do, and act on and return the full id; an unknown id or a prefix that matches several runs answers 404 with the detail `GET` gives, and an ambiguous prefix deletes nothing. On v0.78.0 `/eval` answered 200 with an empty `eval_results` for an id that names no run; it now answers 404, and an existing run with no eval rows still answers 200 with an empty list (#3182, #3088 B-3).
