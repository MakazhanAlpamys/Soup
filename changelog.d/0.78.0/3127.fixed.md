- `soup loop` now skips, and counts in `feedback_lines_skipped`, a conversation line whose `id` or a feedback line whose `response_id` is not a UUID in canonical lowercase form, as `docs/loop-formats.md` requires. Such an edit used to get a paraphrase record that was never read back, so the paraphraser was asked again in every iteration and `paraphrases.jsonl` kept growing. Lines like these, uppercase and braced UUIDs included, were harvested and paraphrased in v0.78.0 and are now skipped: a client that writes its own ids has to write them as lowercase UUIDs. `conversation_id` is still the client's own key, and the logs `soup serve` writes are not affected.
