- `soup serve --adapters` refuses a LoRA adapter as `--model` with exit 2 before any model loads, naming both flags. Before, the server started, and every request that selected no adapter (or a name outside `--adapters`) was answered by the bare base with every adapter disabled, while the `--model` adapter could not be selected. Migration: a command that passes an adapter as `--model` together with `--adapters` used to start and now exits 2; pass the adapter's base as `--model` and add the adapter to `--adapters` (for example `--model ./base --adapters main=./adapter --adapters b=./b`), or merge the adapter first with `soup merge`. `--model` must be a directory on disk, so a base that exists only on the Hub has to be downloaded first.
