- Preserve the training row order when resuming a new single-process Transformers text SFT checkpoint with rewind enabled. A fresh run with rewind enabled now uses the same seeded row order as a fresh run without rewind, so the same seed can produce a different order than in Soup 0.78.x. A checkpoint written before this fix resumes with the corrected order for the remaining rows. Exact reconstruction of its original prefix is unverified. Reported by @harshitthek in #3344. (#3361)
