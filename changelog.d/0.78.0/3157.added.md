- `soup ingest --source langsmith --pull` fetches the LLM runs of a LangSmith tracing project live, without an export step. It reads `LANGSMITH_API_KEY` and `LANGSMITH_PROJECT`, plus `LANGSMITH_ENDPOINT` for another region or a self-hosted instance. One row per LLM run; chain and tool runs give none. The host checks, bounds and `--since` / `--max-pages` / `--allow-private-host` work as for `--source langfuse --pull`. (#204 by @omardmv in #3157)
