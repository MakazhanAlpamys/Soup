- `soup data mix --apply` in v0.78.0 printed snippets for recipes with a quoted number, a boolean, a non-finite value (`.nan`, `.inf`, `-.inf`), a negative weight, a mapping, or a single string in `data.interleave.probs`. These recipes now exit with code 2 before printing the snippet. Write `probs` as a YAML list of finite, non-negative numbers. (#3118)
