- `soup data convert --to alpaca` and `soup data download --format alpaca` no longer shorten a conversation to its last exchange: a row with more turns than alpaca holds (more than one system, user or assistant message, or a role alpaca has no slot for) is refused, and a dataset where every row is refused exits 1. Migration: multi-turn rows are now counted as failed instead of being shortened, so convert those datasets to `sharegpt` or `chatml`, which hold the whole conversation. `soup data download --format <target>` also exits 1 and writes nothing when no row converts to the target; it used to write the downloaded rows unchanged and exit 0, so drop `--format` to keep the rows as downloaded.
