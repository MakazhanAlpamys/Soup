- `training.fp16_init_scale` sets where the fp16 GradScaler starts: a power of two from 1 to 65536, unset keeps torch's 65536. The scaler halves on every step whose gradients overflow and skips that step, so a model that overflows well below its start skips its first optimizer steps; a lower start trains from the first step, and the scaler still grows and backs off as usual. Transformers SFT only (`task: sft`, `backend: transformers`); a run with no plain fp16 GradScaler (such as bf16) prints a note and ignores the key. (#3399 by @nurseit14)
