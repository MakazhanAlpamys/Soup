- SFT runs with the rewind flight recorder (`training.rewind_log`, on by default) shuffle from the seed again. The recorder wraps the train sampler, which hid the plain random sampler from Accelerate, so Accelerate skipped its seeded sampler and the run drew its data order from the global RNG: `training.data_seed` had no effect, and unrelated RNG use before training changed the order. The wrapper now applies Accelerate's seeded-sampler swap itself, with Accelerate's own arguments. (#3379 by @nurseit14)
