- **`training.prefix_tree`: training batches laid out as prefix trees (#3138).** Tokens that several examples begin with and that are not trained on are held once per row. Each row has a 4D attention mask (a token attends to itself and its ancestors) and `position_ids` equal to the depth in the tree. The loss and its gradient are those of the ordinary batch holding the same examples, to rounding. A step runs the trees' tokens instead of the sum of the examples' lengths. A step is still at most `batch_size` rows of `data.max_length` tokens, so the option is allowed beside `stream_layers`. Before the first step the trainer checks the model on real training examples and refuses one that does not reproduce the ordinary batch's logits. The option covers `task: sft`, `modality: text`, a single process and the transformers backend. It is refused beside `packing`, `multipack`, `stream_loss_chunk`, `neftune_alpha`, `curriculum`, `data.format: raft`, `data.replay` and `data.interleave`. It is refused beside a non-zero `training.lora.dropout`, so the default 0.05 has to be set to 0. A model that applies dropout in training is refused before the first step. These are refusals of the new key only: no configuration that loads on v0.78.0 is refused. An epoch has fewer optimizer steps, so runs compare by wall time or examples seen.
