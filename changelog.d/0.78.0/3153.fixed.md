- `soup export --format gguf-ud` now treats a `--gguf-flavour` the same however it is spelled. A flavour not written in upper case, such as `iq2_m`, skipped the importance matrix and ignored `--calibration-data`, was not refused without it, and a lower-case `ud-` flavour reached `llama-quantize` with its prefix. Migration: lower-case `iq3_xxs` and `iq3_xs` used to quantize without an importance matrix on an older `--llama-cpp` build and are now refused without `--calibration-data` (exit 1), like their upper-case forms, so pass `--calibration-data <jsonl>`; the calibration file is now used for every spelling.
