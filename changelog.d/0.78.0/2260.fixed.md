- **`mini_format_json` now checks the JSON shape each prompt asks for (#1192 by @AaronProbha18 in #2260).**
  It used to accept any JSON object or array, so a model answering `{"ok": true}`
  to every prompt scored 1.000. Each of the 40 rows now carries the shape its
  prompt states (key names, value types, array length, exact keys), and the
  scorer checks it. Qwen2.5-1.5B-Instruct measures 0.900 against 0.500 on
  SmolLM2-135M-Instruct. This is a scorer change. `BUNDLED_SCORER_REVISION` moves
  to 8. For upgrades, a baseline with an earlier scorer revision (a
  `--write-baseline` file or a registry eval row) still loads and is compared.
  `soup eval gate --baseline` and `soup ship --baseline` warn about the
  `scorer_revision` mismatch whichever suites it holds. A stored
  `mini_format_json` score used the container-only rule, so the comparison can
  show a drop caused by the scorer change. Re-measure with
  `soup eval gate --suite <suite.yaml> --model <id> --write-baseline baseline.json`.
