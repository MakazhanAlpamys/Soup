- **A LoRA adapter trained on a layer-streamed base can be reloaded into a streamed base for inference.** `soup_cli.utils.stream_inference.build_streamed_inference_model(adapter=...)` takes the directory `soup train` saved, places the adapter on the streamed base the way the trainer does, keeps every parameter frozen, and refuses by name a missing or partial adapter, a non-LoRA adapter, one that uses `modules_to_save` or DoRA, or one whose tensors do not fit the base; on CPU its logits equal the trained model's bit for bit.
