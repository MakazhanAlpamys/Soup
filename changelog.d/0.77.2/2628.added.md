- **A pre-quantised bitsandbytes NF4 checkpoint can be imported into the layer-stream shard store byte for byte (#2628).** `soup_cli.utils.nf4_serialized.import_nf4_checkpoint()` copies the published packed weights and statistics of a double-quantised NF4 checkpoint (for example `unsloth/Qwen3-32B-bnb-4bit`) into Soup's shard layout with no dequantise or requantise step, refuses anything it cannot carry over exactly (FP4, 8-bit, non-nested, an unsupported block size, a mismatched shape, a corrupt scale, a truncated file) and re-reads every shard to compare it with the source. It copies in bounded 8 MiB reads and never maps a file. It is not wired into `soup train` yet, which still refuses a pre-quantised base.
