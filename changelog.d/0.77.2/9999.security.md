- A crash bundle (`.crash`) and a `.can` written by `soup can pack` or `soup can fork` no longer hold credentials: URL userinfo and sensitive query parameters, common API-token shapes, `Authorization` / `Bearer` headers, JWTs, private-key blocks and values stored under credential-named config keys are replaced with `<redacted>` before anything is written. `soup can pack` and `soup can fork` print the key paths they changed, never the values, so a can packed from a config that carried a credential now holds `<redacted>` in its place; a crash bundle records counts only.
