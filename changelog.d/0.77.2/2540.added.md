- **`soup loop watch --detach` leaves a PID file and a log, and refuses a second `--detach`** (#2540): the detached daemon's pid goes to `.soup/loop.pid` (JSON: pid, start time, log path) and its output to `.soup/loop.log` (appended; it used to be discarded; rotated at 10 MB, keeping one old file as `.soup/loop.log.1`). A second `--detach` is refused while that pid is alive (a foreground `soup loop watch` never reads the PID file, so it is not refused), a stale file is replaced, the daemon removes its own file when it exits, and `soup loop status` shows whether it runs.
