- **`soup loop watch --detach` leaves a PID file and a log, and refuses a second daemon** (#2540): the detached daemon's pid goes to `.soup/loop.pid` (JSON: pid, start time, log path) and its output to `.soup/loop.log` (appended; it used to be discarded). A second `--detach` is refused while that pid is alive, a stale file is replaced, the daemon removes its own file when it exits, and `soup loop status` shows whether it runs.
