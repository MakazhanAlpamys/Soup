- **`soup push --collection` now rejects an invalid slug before any upload (#2824).** The slug check used to run after `create_repo`, `upload_folder` and the model-card upload, so a typo published the whole model first and a retry uploaded it again. `validate_collection_slug` is unchanged; it now runs with the other argument checks, before the first Hub call. A regression test with a fake `HfApi` asserts that `create_repo`, `upload_folder` and `upload_file` are never reached for a bad slug.
