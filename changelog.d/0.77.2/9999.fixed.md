- A crash bundle (`.crash`) and a packed or forked `.can` no longer contain credentials. Before anything is written, these are replaced with `<redacted>` in the error message, the traceback, the metrics tail and the config: the userinfo of a URL and the value of a sensitive query or fragment parameter (`token`, `api_key`, `X-Amz-Signature`, ...); Hugging Face, `sk-` / `sk-ant-`, GitHub, AWS, Google, Slack and W&B keys; `Authorization` and `Bearer` headers; JWTs; PEM private-key blocks; and `KEY=value` pairs whose key name says it is a credential. A string under a config key named like a token, secret, password, API key, credential, cookie or session is replaced by key name, while names such as `max_new_tokens` and `tokenizer` stay readable. A crash bundle records how many values were redacted (counts only), and `soup can pack` / `soup can fork` print the key paths that were changed, never the values. No migration is needed. (#9999)
