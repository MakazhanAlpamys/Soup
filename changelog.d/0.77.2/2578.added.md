- **`training.save_strategy` (`steps` | `epoch` | `no`) turns off or thins out intermediate `checkpoint-N` folders (#2575, #2578).** transformers saves a checkpoint at the last step whenever the strategy is `steps`, and Soup never set one, so every run left a `checkpoint-N` beside the final adapter. The default `steps` keeps today's behaviour; `no` writes none (the final adapter or model is still saved) and `epoch` saves once per epoch. One helper, `soup_cli.trainer.save_args.save_kwargs`, now builds the save arguments for all 19 Hugging Face based wrappers. Quote the value in YAML (an unquoted `no` is a bool). `epoch` and `no` are refused together with an explicit `save_steps`, on `backend: mlx` and on `task: unlearn`. `soup migrate` carries `save_strategy` over from axolotl, LLaMA-Factory and unsloth.
