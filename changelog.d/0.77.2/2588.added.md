- **The continual-learning loop judges a candidate by the corrections it learned (#2588).** Held-out corrections (a 30% split by the last user message, kept aside one training iteration, then graduated into training) and paraphrases of trained corrections go to `soup ship --gate loop-v2` in the verify stage, and its evidence is recorded in the iteration line (`verdict.gate`, `corrections`, `held_out`). With 1 to 4 trainable corrections the loop waits and says so (`Waiting: 4/5 trainable corrections ...`, also a `waiting` row in `soup loop status`). Rows count as trained only when the version that used them is promoted, so a rejected candidate's rows come back; `soup loop rollback` restores the cursor. When there are no corrections to check, the canary's ratings decide.
