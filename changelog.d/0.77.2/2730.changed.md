- `soup serve --max-tokens` above 16384 is refused at startup with exit 2 as of v0.78.0, before any backend loads, with the message a value below 1 already gets: `--max-tokens: must be between 1 and 16384 (got N).` A request that omits `max_tokens` takes `--max-tokens`, so a larger value let such a request generate more than the 16384 tokens any request can ask for. The check is the same on the transformers, vLLM, SGLang and MII backends. Migration: pass a `--max-tokens` of 16384 or less; 16384 is also the most a request's own `max_tokens` can be (#2730 reported by @abdumutalipabay0, fixed by @abdulwaarith0 in #2730).
