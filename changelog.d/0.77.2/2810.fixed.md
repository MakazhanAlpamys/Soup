- A training run's step rows record the speed the live panel shows: optimizer steps per second since the first logged step. Hugging Face sets `train_steps_per_second` only in the final summary log, so every step row used to store `speed` 0.0, as if measured, and the Web UI speed chart drew a flat zero line. The first step row now stores `null`, since there is no interval to measure yet, and the chart leaves a gap there; the chart's axis now reads Steps/sec instead of Tokens/sec, which was never what the column held; the final summary row still records Hugging Face's `train_steps_per_second`. Runs recorded before this change keep their 0.0 step speeds; nothing rewrites them. PPO and MLX GRPO, which log their metrics without this callback, still record 0.0.
