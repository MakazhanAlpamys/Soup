- **`runs.loss_summary_kind` and `metrics.kind` say what a stored loss and a metrics row are:** two nullable columns, added in place to an existing `experiments.db` (older rows read NULL). A run's loss is `per_step`, `mean` or `unavailable`; a metrics row is `train`, `eval` or `summary`. `GET /api/runs/{id}`, `GET /api/runs/{id}/metrics` and the live metric event return them, and an unknown value is refused before anything is written (#2589).
