- **An empty run id no longer resolves to the only run (#2937 by @Adul23 in #PRNUM).** `soup runs delete "" --force` with a single recorded run deleted it and exited 0, because the prefix lookup turned the empty id into a pattern that matched every run; the empty id now finds no run, so every command that takes a run id prints `Run not found` and exits 1, while exact ids and real prefixes resolve as before.
