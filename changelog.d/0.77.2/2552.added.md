- **`soup eval retention` measures forgetting across a series of model versions (#2551, #2552).** It keeps a ledger of control tasks (held-out task-eval JSONL files, the format `soup ship --task-eval` reads, each pinned by SHA-256) and the accuracy every recorded version got on each. A run scores the candidate (`--model`, optional `--adapter`) on every control task with one loaded model, compares each task with the best score any earlier version had, and reports mean forgetting and backward transfer; a drop beyond `--threshold` (default 0.05) exits `2`. `--record` appends the version; without it nothing is written. It is a measurement only and not part of the `soup ship` verdict.
