- **`soup loop` verifies with `soup ship` and never skips silently** (#2512): the pre-wired check loaded `--eval` as an eval-gate suite while the docs passed a `soup eval lock` file, so every verdict was `SKIPPED` without a reason and nothing rolled out. The new `soup loop init --verify` (default `ship`: a `soup ship` verdict of the trained adapter against the production version, `--eval` = a task-eval JSONL; or `eval-gate`) is saved in `loop.yaml`; `--eval` is checked at `init --pre-wired` and `watch --pre-wired`, a lock file gets its own message, and a skipped verdict keeps its reason in the iteration record. Older `loop.yaml` files keep the eval gate. Migration: on an existing loop, `soup loop set verify ship` (or `eval-gate`) changes the check without `--force`; `soup loop init` on an existing loop would reset production, canary, cursors, counters and versions.
