- **A library of Triton kernels for the Qwen2 QLoRA SFT step, `soup_cli.kernels.packed_lora` (#9999).** No config key and no CLI change: nothing reads it yet, the trainer wiring follows. NF4 decode (bit-identical to bitsandbytes), RMSNorm, RoPE, SwiGLU, a logit-free head and loss, an int8 MLP input gradient with a start-up check and stochastic rounding of the gradients, a saved-activation stash in GPU or pinned host memory instead of gradient checkpointing, and a planner for a GPU memory budget. Loss and LoRA gradients match the stock forward on tiny models and on Qwen2.5-1.5B (loss within 0.5 %, gradient cosine 0.999 exact / 0.994 int8); on Qwen2.5-7B QLoRA on an RTX 4090 the challenge build ran 1.51x the checkpointed Unsloth at 6,515 MiB and 4,576 tok/s, with last-16-step loss within +0.04 % of plain Soup (3 seeds, 100 steps). Built on the Soup Kernel Challenge submission of team Luck, with ideas from teams 21, Null Pointers, DarkDaur and OrbiTeam.
