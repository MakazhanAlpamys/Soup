- **`soup serve --adapter-dir` and `POST /v1/adapters/load`** (#2516): a LoRA adapter from `--adapter-dir` can be loaded into a running server (transformers backend) without a restart; it is not activated. The route needs `--tool-auth-token` on every bind, refuses a path outside `--adapter-dir` (realpath), a directory without `adapter_config.json`, pickle weights, a duplicate name and more than 16 runtime loads.
