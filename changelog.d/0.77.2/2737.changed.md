- `soup serve --adapters` refuses a LoRA adapter as `--model` with exit 2 before any model loads, naming both flags. Before, the server started, and every request that selected no adapter (or a name outside `--adapters`) was answered by the bare base with every adapter disabled, while the `--model` adapter could not be selected. Upgrade note: a command that passes an adapter as `--model` together with `--adapters` now stops at start; pass the adapter's base as `--model` and add the adapter to `--adapters` (for example `--model org/base --adapters main=./adapter --adapters b=./b`), or merge it first with `soup merge`.
