- `scoring: "tool_call_args_subset"` counts a row as Correct only at full credit: the right function with every expected argument present and matching. The function name and the arguments are worth `0.5` each, and a row used to be matched at `0.5`, so a call with every argument wrong, with no arguments, or to the wrong tool counted as Correct, and a model that never got an argument right could report 100% Accuracy. The per-row `score` keeps its partial credit, so the eval gate and the other callers that average it are unchanged. This reverses the `0.5` matched threshold that #1755 kept. **Migration:** `soup eval custom`, `soup ship` metric mode and the retention check now report a lower Accuracy for suites that use this scorer. Stored results are not rewritten and do not compare with new ones; re-run the suite on both models with this version to get comparable numbers. (#2811 by @AlibekBerik in #2939)
