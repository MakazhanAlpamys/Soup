- The experiment tracker stores a run's `output_dir` as an absolute path, so `soup runs --cwd-only`, `soup runs clean`, `soup runs curriculum-curve` and `soup rewind` find a newly finished run's output in the directory it trained in, not in the directory they are run from. Runs recorded before this release keep their relative `output_dir`, which is still resolved against the current directory exactly as before: run `soup runs clean <id>` or `curriculum-curve` for such a run from the directory it trained in, as today. The Web UI API (`GET /api/runs`, `GET /api/runs/{id}`) and MCP tools (`runs_list`, `runs_show`) return `output_dir` relative to the server working directory when under it, and only its last path component otherwise.
