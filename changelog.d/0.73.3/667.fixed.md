- **`soup doctor` now reports MLX, with the real version (#659).**
  `_get_mlx_info()` had no caller: the helper, its docstring ("Surface MLX info
  in the doctor report") and its test all existed while `doctor` never invoked
  it, so `soup doctor` printed nothing about MLX on any machine — the panel a
  user reaches for to ask whether Soup can see their MLX install. `doctor` now
  renders an MLX panel when MLX is importable and, the case that most needs
  saying, when the box is an Apple Silicon Mac with MLX absent (with the
  `soup-cli[mlx]` install hint); machines that are neither still get no panel,
  and an absent optional extra is not counted as an environment issue.
  `get_mlx_version()` also returned `"unknown"` on every correctly installed
  machine: it read `mlx.__version__`, which the top-level package does not
  export. It now reads `mlx.core.__version__`, then the package surface, then
  the installed distribution metadata, keeping `"unknown"` as a genuine last
  resort and `None` when MLX is not installed. The replaced test drove the
  helper, which is why this survived; the new tests drive the **command** and
  include a control that fails if the panel is rendered unconditionally.
