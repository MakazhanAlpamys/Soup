- **`soup loop` no longer reads the served model directory as traces** (#2507): the pre-wired harvest tried the served model path when it was a local directory, so a model directory holding `*.jsonl` files (a dataset next to the weights) was harvested as serve logs. The trace directory is now `SOUP_LOOP_TRACE_DIR`, else the new `soup loop init --trace-dir` (saved as `trace_dir` in `loop.yaml`), else `.soup-loops/traces` as before; `soup loop init` and `soup loop status` show which one applies, and a path that is a file is refused.
