- **`soup loop` reads traces only from the configured directory** (#2507): the pre-wired harvest no longer guesses its trace directory (it tried the served model path, then `.soup-loops/traces`, so a model directory holding `*.jsonl` files was read as serve logs). The new `soup loop init --trace-dir` (saved as `trace_dir` in `loop.yaml`) or `SOUP_LOOP_TRACE_DIR` names it; a path that is a file is refused, and `soup loop watch --pre-wired` warns when the old `.soup-loops/traces` exists but is no longer read.
