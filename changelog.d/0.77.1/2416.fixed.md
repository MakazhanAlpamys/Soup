- **`soup ship` loads and stamps `float16` for the live eval on CUDA cards without bf16 units (#2409 by @Nari-Ab in #2416).** The live eval picked `bfloat16` on any CUDA device, so on a T4, V100 or RTX 20xx it evaluated in a dtype the card has no units for while training had already moved to `float16` through `bf16_fp16_flags` (#385, #387), and the verdict and `--emit-evidence` recorded `bfloat16`. It now asks the same helper: `bfloat16` on cards with bf16, `float16` on older CUDA cards, `float32` on CPU. `float16` is an accepted numerics stamp in the `full` family, so evidence from a T4 is not stale against a bf16 run of the same recipe.
