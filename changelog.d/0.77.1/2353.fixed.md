- `soup_cli.utils.embed.embed_texts` and other callers passing `device="auto"` no longer fail with a PyTorch `RuntimeError: Expected one of cpu, cuda... device type at start of device string: auto`. `resolve_device` now treats `"auto"` as an instruction to probe available compute devices (CUDA, then Apple Silicon MPS, falling back to CPU) instead of passing the string verbatim (#2279 in #2353).
