- A wrong-typed value in one of 38 `training` fields (for example `minillm_enabled: 0`, `fp8_attention: "false"` or `num_labels: true`) is now a config validation error that names `training -> <field>`, with exit 1 from both `soup train` and `soup plan`. It used to escape the schema as a bare `TypeError`: `soup train` printed `Error: TypeError: ...` and `soup plan` exited 2, and `load_config_from_string` raised `TypeError` instead of its documented `ValueError`. The bool-flag messages now name the field rather than a release (#2382, closes #2366).
