- **A row Soup cannot interpret is named, not silently dropped.** `soup data clean` now says when the rows are in no recognised format and repeats the detection error with the first offending key set instead of printing `No issues found` for a file it could not read; `soup ab` counts the rows it could not use by reason (invalid JSON, not an object, arm missing or not control/treatment, metric missing or non-numeric, metric not finite) and prints them when the usable total is below the threshold; and `soup rewind --json` writes a non-finite loss, baseline or ratio as `null` with `non_finite: true`, so the file parses as strict JSON instead of carrying bare `NaN` / `Infinity` (#1818 by @EtherealMelon in #2281).
