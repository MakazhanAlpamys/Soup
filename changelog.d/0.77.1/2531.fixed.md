- **`soup loop` trains only when new feedback arrived** (#2531): a cycle that had just promoted a canary retrained on the same old feedback and started a new canary. Training now runs only when at least `soup loop init --min-new-pairs` (default 1) preference pairs are newer than the last training run; it still trains on all pairs collected so far, since each iteration trains a fresh adapter from the base. The cursor (`harvest_cursor_ts` in `loop.yaml`) moves only after a training run, and `soup loop status` shows it.
