- **The bundled DPO examples train on `backend: transformers` (#1849 by @dryn85-max in #1874).**
  `dpo_sample.jsonl` and `chat_preferences.jsonl` write `prompt` as a string and `chosen` /
  `rejected` as conversations that repeat the user turn. TRL took those rows as text, so
  `dpo_example.yaml`, `dpo_chat.yaml` and the `dpo_demo` / `sharegpt_demo` bundles stopped with
  `'list' object has no attribute 'endswith'` on `dpo` and `ipo`, and with a type error on `bco`.
  The `dpo` format now rewrites that layout into TRL's conversational one: the shared leading turns
  become the prompt and the rest become the completions. `reward_model` no longer repeats the
  prompt in front of each such conversation, so a reward model trained on this layout before
  scores slightly different text now. A row with one string and one message-list completion is
  refused. Try: `soup train --config examples/configs/dpo_example.yaml`.
