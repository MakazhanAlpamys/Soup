- **KL calibration probability calculation now uses numerically stable log-softmax without artificial flooring (#1772 in #1780).** `eval.calibrate.kl_divergence` previously floored candidate probabilities at `1e-12` before taking logarithms, which truncated large logit divergences (gaps > ~27.6) and caused `run_calibration` to return `MINOR` when the actual divergence exceeded the documented `MAJOR` threshold (>= 0.20). KL divergence is now evaluated directly using stable log-probabilities via `_log_softmax`, preserving monotonic scaling for large divergence gaps without underestimating quant-calibration deltas.
