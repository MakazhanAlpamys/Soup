Four CLI message gaps from the v0.76.0 smoke (#1830):

- `soup expect` with a missing data or suite file now prints
  `data file not found: '<path>'` / `suite file not found: '<path>'`
  instead of the bare path (exit 3 unchanged).
- `soup lock check` / `soup lock show` on a corrupt lock file now report
  `lock file '<path>' is not valid JSON: <detail>` instead of a raw
  `Expecting value: line 1 column 1` that did not name the file.
- The `soup expect` module docstring no longer claims exit code 3 on suite
  failure; it now matches `utils/exit_codes.py` (2 = gate failure,
  3 = usage error).
- `soup draft measure` / `soup draft distill` on a core-only install now
  print the `pip install "soup-cli[train]"` hint when `transformers` is
  missing, instead of a bare `No module named 'transformers'`
  (exit 1 unchanged).
