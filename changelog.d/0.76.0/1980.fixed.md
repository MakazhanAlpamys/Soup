- The RL checkpoint manifest now reports `has_ref_model: false` and `has_rollout_buffer: false`, because no save writes reference-model or rollout-buffer state. Before, it copied `training.rl_checkpoint_include_ref_model` and `training.rl_checkpoint_include_rollout_buffer` from the config, so a checkpoint holding only the adapter and optimizer claimed both. Setting either flag to `true` now warns at load as a staged field and is refused from v0.77 (#808 by @Srinivasan8888 in #1980).
