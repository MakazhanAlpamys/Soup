- **Export behavior verification gate: `soup eval export-check` (#2048 by @CODING-DARSH in #2143).**
  Verifies that an exported model artifact (merged safetensors directory produced by `soup merge`)
  preserves the behavioral delta of the LoRA adapter it came from. Compares greedy decoding of base,
  base+adapter reference (via PEFT), and the exported model on user-supplied `--prompts` (plain text,
  JSONL `"prompt"`, Alpaca `"instruction"`/`"input"`, ChatML `"messages"`, or bare JSON strings).
  Detects when adapter deltas are lost (`DELTA_LOST`) even if raw surface agreement meets
  `--min-agreement`. Reports the 0-based index of the first divergent generated token ID, evaluates
  masked causal next-token NLL across held-out evaluation texts, and rejects unmergable formats
  (standalone GGUF, ONNX, MLX-fused, or adapter directories passed to `--exported`) with exit code 3.
