- **The layer-streaming disk pre-flight no longer under-counts a fused MoE cache under `quantization: 4bit`.** It charged the NF4 rate to every parameter, but the default `fused` expert layout keeps the stacked routed experts at the stream dtype, so for Moonlight-16B-A3B (`deepseek_v3`) it charged 8.23 GB and the sharder then wrote 30.60 GB: a disk could pass the check and fill mid-shard. The cache is now sized from the source safetensors headers (no weight is loaded), tensor by tensor, by the same storage rules the sharder writes with, including the exact NF4 sidecar bytes; for Moonlight it lands within 0.01% of the cache written in both `fused` and `per_expert`. A striped cache splits that same figure over its drives. When the headers cannot be read it falls back to the old rate and the panel says "approximately".
