- **`soup ui` on a loopback bind refuses requests whose `Host` header is not one of the served names (#1829 in #1839).** The three names are the bound host with the bound port and `localhost` / `127.0.0.1` / `[::1]` with the same port; anything else — a foreign name, the wrong port, a missing port, an unparsable or missing header — is answered `403 {"detail": "Host not allowed"}` before any route runs. This closes the hole the #1191 session-cookie check left open, where `Origin` was compared against the request's own `Host` so any request naming the same host on both sides passed. `--public` binds are unchanged and keep the Bearer gate, and the printed login URL is the same as before (#1829 in #1839).
