- **`mini_format_json` now checks the JSON shape each prompt asks for (#1192 by @AaronProbha18 in #2260).**
  It used to accept any JSON object or array, so a model answering `{"ok": true}`
  to every prompt scored 1.000. Each of the 40 rows now carries the shape its
  prompt states (key names, value types, array length, exact keys), and the
  scorer checks it. Qwen2.5-1.5B-Instruct measures 0.900 against 0.500 on
  SmolLM2-135M-Instruct. This is a scorer change: the bundled scorer provenance
  revision moves to 8, so baselines recorded before it warn rather than being
  compared on the new scale.
