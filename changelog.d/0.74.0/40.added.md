- `soup train` accepts `--nodes`, `--node-rank`, `--master-addr`, and `--master-port`
  for multi-node Accelerate launches (#40). `--gpus` is the per-node count, so eight GPUs
  on two nodes launches 16 workers. Launch settings are validated before training;
  multi-node NCCL defaults allow InfiniBand and preserve user overrides.
  `--no-reexec` and `--dry-run` show the command without starting workers.
