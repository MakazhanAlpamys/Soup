- **Sequence-level GSPO objective (#723).** Upgraded `grpo_variant: gspo` from the
  legacy column-centering heuristic to the published Group Sequence Policy Optimization
  algorithm (Qwen, arXiv:2507.18071). Evaluates a length-normalized sequence importance
  ratio $s_i = \exp(\frac{1}{|y_i|} \sum_{t=1}^{|y_i|} (\log p_\text{new} - \log p_\text{old}))$
  and applies sequence-level surrogate clipping with default radius $\varepsilon = 0.2$
  (or operator-supplied `delta`), guaranteeing exact zero gradient at all masked tokens
  and strict batch-permutation invariance.
