- **Token-chunked checkpointed KL distillation (#722).** Added `training.distill_chunk_size`
  and `training.distill_checkpoint` knobs for `task: distill`. Filters student and
  teacher logits to supervised tokens (`labels != -100`) prior to computing the
  divergence, and computes token chunks with optional non-reentrant activation
  checkpointing (`torch.utils.checkpoint.checkpoint(..., use_reentrant=False)`).
  This eliminates intermediate `log_softmax` and divergence activations from the
  autograd tape, drastically reducing peak activation memory on long sequences
  and large vocabularies.
